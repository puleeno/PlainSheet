PlainSheet Addon API

  • Small addons transform the in-memory grid: headers + rows in, transformed rows out.
  • Big addons receive a file path and run on the file (stats, cleanup, export).
  • Python runtime backs the extension library (~/.plainsheet/extensions/main_ext.py).
  • Set PLAINSHEET_DEV=1 to edit extensions in place while debugging.
